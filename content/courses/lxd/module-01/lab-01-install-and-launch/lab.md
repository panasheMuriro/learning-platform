# Lab 1: Install, Initialize & Launch

In this lab, you'll install LXD, initialize it, and launch your first
containers. This is a hands-on lab — use the terminal on the right to run
all commands.

## Prerequisites

- A Linux machine with snap installed
- At least 20 GiB free disk space

## What you'll do

1. Verify LXD is installed (or install it)
2. Initialize LXD with minimal defaults
3. Launch your first container
4. Create a stopped container
5. Start and inspect it

Follow the task instructions on the left. Use the **Check** button after
completing each task to verify your work.
