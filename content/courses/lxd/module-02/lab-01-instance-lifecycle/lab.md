# Lab 1: Instance Lifecycle

In this lab, you'll create a container, configure it with resource limits,
shell into it, create a snapshot, and test backup/restore by breaking and
restoring the instance.

## Prerequisites

- LXD is installed and initialized (Module 01)
- You have an in-browser terminal connected

## What you'll do

1. Launch a container
2. Set resource limits (CPU and memory)
3. Shell in and verify limits are in effect
4. Create a snapshot
5. Break something and restore from snapshot
