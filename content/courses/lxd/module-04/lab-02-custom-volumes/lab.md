# Lab: Custom Volumes

In this lab, you'll create a custom storage volume, attach it to a
container, write data to it, then prove the data survives instance deletion
by attaching it to a new container.

## Prerequisites

- LXD is installed and initialized (Module 01)
- Completed the "Explore Storage Pools" lab (recommended)

## What you'll do

1. Create a custom volume
2. Attach it to a container and write data
3. Delete the container and verify data persists on the volume
