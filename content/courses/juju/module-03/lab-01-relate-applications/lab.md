# Lab 1: Relate & Integrate Applications

## Overview
In this lab, you will deploy two applications and establish an integration between them using compatible endpoints.

## Objectives
1. Create a model named `lab-relate`.
2. Deploy `haproxy` with alias `ingress-proxy` and `haproxy` with alias `backend-service`.
3. Integrate `ingress-proxy:reverseproxy` with `backend-service:website`.
