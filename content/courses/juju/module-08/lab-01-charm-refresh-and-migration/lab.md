# Lab 1: Charm Refresh, Lifecycle & Migration Preparation

In this lab, you will perform live application charm refreshes, adjust charm channels, export running topology bundles, and simulate model migration readiness.

## Objectives
1. Create and switch to model `mod8-refresh-lab`.
2. Deploy the `ubuntu` charm with application name `service-node`.
3. Perform a live charm refresh on `service-node` to update configuration and channel tracks.
4. Export the live model topology to a reproducible bundle `live-topology.yaml`.
5. Verify model readiness for migration workflows.
