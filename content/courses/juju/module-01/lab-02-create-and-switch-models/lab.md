# Lab 2: Create, Configure & Switch Models

## Overview
In this lab, you will practice creating isolated Juju models, switching the active client focus, and adjusting model configuration settings.

## Objectives
1. Create a model named `lab-dev`.
2. Configure a model setting on `lab-dev` (set `logging-config="<root>=INFO"`).
3. Create a second model named `lab-staging` and switch back to `lab-dev`.
