# Lab 2: Pebble Inspection & Container Workload Simulation

## Overview
In this lab, you will explore container and workload process management concepts by deploying an application, executing commands across units, and inspecting runtime state.

## Objectives
1. Create a model named `lab-k8s-pebble`.
2. Deploy `ubuntu` application named `container-app`.
3. Execute a command on `container-app/0` to write a verification marker `/tmp/pebble-sim.ready`.
