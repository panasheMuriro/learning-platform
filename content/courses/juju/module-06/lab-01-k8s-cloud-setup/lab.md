# Lab 1: Kubernetes Cloud Registration & Model Provisioning

## Overview
In this lab, you will practice inspecting cloud definitions in Juju and managing cloud substrates and model registrations.

## Objectives
1. Inspect available clouds in the environment using `juju clouds`.
2. Create a model named `lab-k8s-cloud`.
3. Verify that the model is active and inspect cloud configuration with `juju model-config -m lab-k8s-cloud`.
