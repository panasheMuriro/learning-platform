# Lab 2: Logging & Troubleshooting Workloads

In this lab, you will practice diagnosing unit status, reading live log streams, inspecting agent journals, and simulating hook resolution.

## Objectives
1. Create and switch to the model `mod7-troubleshoot-lab`.
2. Deploy the `ubuntu` charm as `worker-node`.
3. Query Juju debug log entries filtering for specific targets.
4. Execute remote unit diagnostics using `juju exec`.
