# Lab 1: Deploy Charms from Charmhub

## Overview
In this lab, you will create a dedicated model and deploy applications from Charmhub using channel constraints and custom application aliases.

## Objectives
1. Create a new model named `lab-deploy`.
2. Deploy the `ubuntu` charm with custom application alias `app-server` from channel `latest/stable`.
3. Deploy a second application named `worker-node` using the same `ubuntu` charm.
