# Lab 1: Scale Applications & Units

## Overview
In this lab, you will deploy an application and practice scaling it out horizontally by adding units and scaling it back down using unit removal.

## Objectives
1. Create a model named `lab-scale` and deploy `ubuntu` as `worker`.
2. Scale out `worker` by adding 2 additional units (`-n 2`).
3. Scale in by removing a specific unit (`worker/2`).
